List: A List is an ordered and mutable sequence of elements enclosed in square brackets  that allows duplicate values. 
Dictionary: A Dictionary is a mutable collection of unique Key-Value pairs enclosed in curly brackets .  
Set: A Set is an unordered collection of unique elements that automatically removes duplicate values and does not support indexing.                                                                                                      
Conditional Statements : Conditional statements are used to execute specific blocks of code based on whether given conditions evaluate to true or false.
